# StudyScape — Full Project (v1.4.1 + Firestore-wired UI)

Senior capstone, Santa Clara University. Real-time study space monitoring
for SCDI: live occupancy and noise data on a Flutter mobile app.

## Repository structure

```
studyscape/
├── studyscape_edge_node/     ← Runs on Arduino UNO Q in SCDI rooms
│   ├── python/               ← App Lab Python: occupancy + noise + Firestore
│   ├── sketch/               ← STM32 sketch: MAX4466 sampling via Bridge
│   ├── app.yaml              ← App Lab manifest
│   └── README.md             ← Edge node deploy + tuning guide
│
└── studyscape_app/           ← Runs on student phones
    ├── lib/                  ← Flutter / Dart UI + Firestore services
    │   ├── firebase_options.dart   ← Generated by flutterfire configure
    │   ├── services/
    │   │   ├── auth_service.dart       ← Firebase Auth
    │   │   └── firestore_service.dart  ← Live spaces/<id> streams
    │   └── models/space_reading.dart   ← Space data model
    ├── pubspec.yaml          ← firebase_core, cloud_firestore, firebase_auth
    └── README.md
```

## Data flow

```
[USB camera] ──┐
               ├──► [Uno Q] ──► [Firestore: spaces/<id>] ──► [Flutter app]
[MAX4466 mic] ─┘    Python +
                    sketch
```

1. Edge node samples noise (MAX4466 on A0) and occupancy (USB webcam,
   YOLO ONNX or Video Object Detection brick).
2. Every 30 s it writes to `spaces/<space_id>` in Firebase project
   `studyscapescu` (see `studyscape_edge_node/python/firebase_writer.py`).
3. Flutter app reads the same documents via `FirestoreService.watchSpace()`
   in `studyscape_app/lib/services/firestore_service.dart` and renders
   live floor-plan markers.

## Status

- **Edge node v1.4.1** — production-ready. Two interchangeable occupancy
  backends (`brick` default, `yolo` fallback). Pin-mic noise default,
  USB-mic optional. Robust-count aggregation across multiple percentiles
  with persistence-aware hysteresis (changes catch up after ~90 s).
- **Flutter app** — Firebase Auth login + live Firestore streams for
  building-detail and space-insights screens.

## Per-component setup

### Edge node — see `studyscape_edge_node/README.md`

Imports as an Arduino App Lab project. Defaults to YOLO + pin-mic. Switch
backends via env vars (`OCCUPANCY_BACKEND=brick|yolo`,
`NOISE_MODE=pin|usb`) or by editing the defaults near the top of
`python/main.py`.

### Flutter app — see `studyscape_app/README.md`

Standard Flutter project. From `studyscape_app/`:

```bash
flutter pub get          # install Dart packages
flutter run              # build + install on connected device
```

For iOS, you'll need to open `ios/Runner.xcworkspace` once in Xcode to
configure signing (Apple ID, unique bundle identifier).

## Firebase

Both pieces use the **same Firebase project**: `studyscapescu`.

- Edge node auth: service account JSON. Default path
  `/home/arduino/serviceAccount.json` on the Uno Q. The bundled
  `studyscape_edge_node/python/serviceAccountKey.json` is a placeholder —
  paste your real credentials in or set `FIREBASE_SERVICE_ACCOUNT` env
  var to point elsewhere.
- Flutter app auth: `firebase_options.dart` (already configured by
  `flutterfire configure`). End-user authentication via Firebase Auth.

## Where to look first if something's broken

| Symptom                                | First place to look                                       |
|----------------------------------------|-----------------------------------------------------------|
| App shows hardcoded fallback values    | Check `[firebase] no credentials...` in Uno Q console     |
| Markers stay grey / "loading"          | Check Firestore `spaces/<id>` actually has docs           |
| App crashes on launch                  | iOS signing issue — open `ios/Runner.xcworkspace`         |
| Edge node reports `occ=0` always       | Camera not connected, or YOLO ONNX failed to load         |
| Counts oscillate ±1 between reports    | Working as intended — see hysteresis docs in edge README  |
